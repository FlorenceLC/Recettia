    ☁️ Synchronisation GitHub Gist

    Vos recettes sont stockées dans un fichier JSON sur votre GitHub Gist — accessibles sur tous vos appareils, gratuitement, sans limite.

    Configuration (3 minutes) :
    1. Allez sur gist.github.com → créez un nouveau Gist nommé recettai.json avec le contenu [] → notez l'ID du Gist (les chiffres/lettres dans l'URL)
    2. Allez sur github.com/settings/tokens/new → cochez uniquement gist → générez le token → copiez-le
    3. Collez vos deux valeurs ci-dessous et cliquez Enregistrer.
